# حزمة تسليم: Seen — المركز الروحاني والمناسك (Flutter)

هذه الحزمة تحتوي كل ما يحتاجه **Claude Code** لتنفيذ التصميم المعتمد (٨ شاشات) كتطبيق Flutter كامل، بما فيه الحركات التفاعلية والاهتزازات.

## المحتويات

| الملف | الغرض |
|---|---|
| `CLAUDE.md` | تعليمات المشروع الدائمة لـ Claude Code: المبادئ، الحزم، هيكل الكود، قواعد العمل |
| `KICKOFF_PROMPT.md` | الرسالة الأولى التي تلصقها في Claude Code |
| `docs/01-design-tokens.md` | الألوان والخطوط والمسافات والظلال |
| `docs/02-components.md` | المكوّنات المشتركة (أزرار، بطاقات، حلقة الأشواط، شارة السورة…) |
| `docs/03-screens.md` | مواصفات الشاشات الثماني وسلوكها وحالاتها |
| `docs/04-motion-haptics.md` | كل حركة (مدة ومنحنى) وكل اهتزاز لكل تفاعل |
| `docs/05-content.md` | مصادر النص القرآني والتفسير والأدعية وقواعد المراجعة الشرعية |
| `docs/06-build-plan.md` | مراحل البناء ومعايير القبول |
| `design/reference/*.dc.html` | ملفات التصميم الأصلية كمرجع بصري دقيق |

## طريقة الاستخدام

1. أنشئ مجلدًا للمشروع وانسخ فيه محتويات هذه الحزمة.
2. ضع الأصول المرخّصة في `assets/` إن توفرت (خط Tajawal، خط مجمع الملك فهد العثماني، بيانات المصحف، ملفات الصوت).
3. افتح Claude Code داخل المجلد والصق محتوى `KICKOFF_PROMPT.md`.
4. سيعرض خطة ويطرح أسئلته، ثم يبني على مراحل (M0 ← M8) ويختبر بعد كل مرحلة.

## قبل الإطلاق

- مراجعة شرعية لنصوص الأدعية ومصادرها (الحزمة تمنع عرض أي دعاء غير مراجَع في نسخة الإصدار).
- النص القرآني يُحمَّل من مصدر موثّق فقط، ولا يُكتب يدويًا.
- المواقيت والمسافة والاتجاه في التصميم أمثلة؛ التطبيق يحسبها مباشرة من موقع المستخدم.
