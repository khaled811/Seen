  - `DefaultCookieJar._check` is `(secure && https) || !expired`: **the `Secure` flag is not enforced on http, and an expired Secure cookie is still sent over https.** The app therefore wraps the jar with a strict filter and also forbids non-https endpoints outside debug.
  - Host-only cookies (no `Domain`) are stored per exact host and only loaded for that exact host (host scoping confirmed).

It awaits the write before returning, and `CookieManager.onResponse` awaits it before the next interceptor runs (cookie saved before the access token is used). A storage write error rejects the response; a corrupt entry makes `loadForRequest` throw: both are handled in the app's storage/jar wrappers.
  - `persistSession: false` skips session cookies when writing; Max-Age/Expires cookies are persisted.
  - `CookieManager` reads `Set-Cookie` as a list, saves on `onResponse` and on `onError` with a response.
